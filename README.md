 ✈️ MakeMyTrip Landing Page

A responsive travel website landing page inspired by **MakeMyTrip**, built using **HTML5 and CSS3**.  
This project showcases popular destinations, a hero banner, navigation bar, and footer with contact details.

---

## 📌 Features

- Responsive navigation bar
- Hero section with background image
- Popular destinations section with cards
- Clean and modern UI
- Fully responsive using CSS Grid & Media Queries
- Sticky header
- Footer with quick links and contact info

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **CSS Grid**
- **Flexbox**
- **Media Queries**
